# Licensing

This repository uses different licences for its ontology and its supporting software. These are licences for different assets, rather than a choice of either licence for every file.

| Material authored for iCARE Onto | Licence |
| --- | --- |
| Ontology modules, controlled vocabularies and original alignment assertions; original source specifications and competency-question records | [Creative Commons Attribution 4.0 International (CC BY 4.0)](LICENSES/CC-BY-4.0.txt) |
| Original ontology and catalogue documentation, resource metadata and annotations, learning-activity content, example/test datasets, generated knowledge graphs and validation reports | [CC BY 4.0](LICENSES/CC-BY-4.0.txt) |
| Executable source and test code, schemas, SHACL validation rules, software configuration, input templates and software usage documentation | [MIT](LICENSES/MIT.txt) |

The scope follows the material's purpose, wherever it is stored. For example, the scripts under `serialisation/` are MIT-licensed, while the ontology they generate is CC BY 4.0. Test programs are MIT-licensed; their authored test datasets and result reports are CC BY 4.0. In documents covering both the ontology and software use, the software instructions are additionally available under MIT as associated software documentation.
